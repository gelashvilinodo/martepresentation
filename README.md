# მართეო — ანიმაციური პრეზენტაცია

ვიდეოს მსგავსი, ავტომატურად გადამრთველი პრეზენტაცია საიტისთვის. ერთი HTML ფაილია, build ნაბიჯი არ სჭირდება.

## გაშვება

გახსენი `index.html` ბრაუზერში, ან ატვირთე საქაღალდე (`index.html`, `config.js`, `assets/`) ჰოსტინგზე.

ლოკალურად:

```bash
python3 -m http.server 8000
# შემდეგ გახსენი http://localhost:8000
```

## მართვა

| მოქმედება | კლავიში / ჟესტი |
|---|---|
| პაუზა / გაგრძელება | `Space` (ან `K`), ეკრანზე დაჭერა, ▶︎/❚❚ ღილაკი |
| წინ / უკან | `→` / `←`, ტელეფონზე swipe |
| სრული ეკრანი | `F`, ორმაგი დაჭერა, ⛶ ღილაკი |
| კონკრეტულ სლაიდზე გადასვლა | ქვედა პროგრესის ზოლზე დაჭერა |

სლაიდები ყოველ 6 წამში იცვლება, ბოლოს კი პრეზენტაცია თავიდან იწყება.

## რედაქტირება

- **`config.js`**: საიტის ბმული (QR კოდიც აქედან იქმნება), კონტაქტები, რიცხვები, სქრინშოტები და სლაიდის ხანგრძლივობა.
- **`index.html`**: სლაიდების ტექსტი. თითოეული სლაიდი `<!-- N. სახელი -->` კომენტარითაა მონიშნული.
- **რიცხვების სლაიდი** (მე-7) მხოლოდ მაშინ ჩანს, როცა `config.js`-ში `stats` შევსებულია.
- **სქრინშოტები**: ჩადე სურათები, მაგ. `assets/screens/`-ში, და მიუთითე `config.js`-ის `screenshots` ველში. სანამ ეს ველი ცარიელია, ჩანს ჩაშენებული მაკეტი.

## საიტზე ჩასმა (iframe)

```html
<iframe src="/presentation/index.html"
        style="width:100%;aspect-ratio:16/9;border:0;border-radius:16px"
        allow="fullscreen" allowfullscreen loading="lazy"
        title="მართეოს პრეზენტაცია"></iframe>
```

`?autoplay=0`: პრეზენტაცია პაუზით იწყება.

## ტექნიკური დეტალები

- შრიფტი: Noto Sans Georgian (Google Fonts).
- QR კოდი გენერირდება ადგილზე (`assets/vendor/qrcode.js`, MIT, Kazuhiko Arase).
- სცენის ზომაა 1920×1080. ის ნებისმიერ ეკრანს ერგება და პროპორცია ყოველთვის 16:9 რჩება.
